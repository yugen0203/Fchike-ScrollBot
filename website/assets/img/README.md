# 画像スロットについて

このサイトのキービジュアル・装飾は、軽量化のため **SVG/CSSで自動生成** しています
（`assets/js/theme.js` がテーマごとに描画）。そのため画像ファイルは必須ではありません。

写真を使いたい場合は、このフォルダに画像を置き、HTML側の該当箇所に差し込んでください。

## 推奨スロット（任意）

| 用途 | 推奨ファイル名 | 推奨サイズ | 差し込み先 |
|---|---|---|---|
| OGP画像（SNSシェア） | `ogp.png` | 1200×630 | 各HTMLの `<meta property="og:image">` を追加 |
| トップのヒーロー写真 | `hero.webp` | 1600×1200 | `index.html` の `.hero__art` を `<img>` に置換 |
| サービス各種の写真 | `service-*.webp` | 800×600 | `services.html` の各カード |
| 会社・オフィス写真 | `office.webp` | 1600×900 | `company.html` |
| ファビコン | `favicon.svg` / `favicon.ico` | — | 各HTMLの `<head>` に `<link rel="icon">` |

## 画像生成ツールでの作り方（後日）

`/gpt image2` などの画像生成が使える環境では、例えば次のようなプロンプトで作成し、
WebP（または最適化済みPNG/JPG）に変換してここへ保存してください。

- ヒーロー: 「未来的でクリーンなIT/ソフトウェア開発のアブストラクト、ブランドカラーのグラデーション、余白多め、テキストなし」
- サービス: 各サービス（アプリ/Web/動画/研修 等）を象徴するミニマルなイラスト

> 注意: 画像は必ず軽量化（WebP化・適切なサイズ）してください。「サイトを重くしない」方針のためです。
> アイコンは Font Awesome を使用しているため、画像化は不要です。
